# Charts: More Options

## Overview

More Options lets you refine which charts are displayed and how runs are filtered, without changing any stored data. It helps you focus on the exact slice of data you want to review.

## When to Use This

- You want to display a different set of charts.
- You want to save an ordered list of favorite charts.
- You want to apply a rolling window to recent runs or days.
- You want a moving average to smooth short-term variability.
- You want to filter charts to a specific Ultimate Weapon, Guardian Chip, or Bot.

## How to Use

1. Select **Charts** in the navigation.
2. Select **More options** to expand the panel.
3. Select one or more entries in **Charts** to control which charts appear. Hold **Ctrl** (Windows) or **Cmd** (Mac) to select multiple entries.
4. Use **Favorites** to add charts to your ordered favorites list.
5. Drag favorites to reorder them, or remove charts you no longer want.
6. Select **Save favorites** to apply the ordered favorites list to your dashboard.
7. Select **Rolling window** and **Rolling window size** to limit the most recent runs or days.
8. Select **Moving average window** to smooth the line charts.
9. Select **Ultimate Weapon**, **Guardian Chip**, or **Bot** to filter to runs where the item appears.
10. Select **Apply** to refresh the dashboard.

## How to Read the Results

- The chart list determines which charts render on the dashboard.
- Favorites determine the default chart list and order when you load the dashboard.
- Rolling window filters limit the run set after your date, tier, and preset filters are applied.
- Moving averages smooth chart lines by averaging adjacent points.
- Item filters narrow the run set to runs where the selected item appears in the report.

## Notes & Limitations

> **Note**
> Rolling windows apply after date range, tier, and preset filters.

> **Note**
> Moving averages affect what you see on the chart but do not change your saved data.

> **Caution**
> Some charts require item selections. If a chart depends on an item, it may show no data until that item is selected.
