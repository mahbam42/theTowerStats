# Charts: Advanced Analysis

## Overview

Advanced Analysis collects the tools that compare snapshots, summarize changes, and export derived metrics. It is accessed through the Advice modal on the Charts dashboard.

## When to Use This

- You want Advice summaries based on saved snapshots.
- You want a goal-aware summary that weights multiple metrics.
- You want to export derived metrics as a CSV snapshot.

## How to Use

1. Select **Charts** in the navigation.
2. Select **Advice** to open the Advice modal.
3. Select **Snapshot A** to anchor the comparison.
4. Select a comparison mode for Advice.
5. Select **Snapshot B** when comparing snapshot to snapshot.
6. Review or adjust the goal weights for a goal-aware summary.
7. Select **Export derived metrics (CSV)** to download a snapshot of derived chart values.
8. Select **Close** to return to the dashboard.

## How to Read the Results

- Advice summaries describe observed differences between the selected snapshots and the current filters.
- Goal-aware summaries report a weighted percent-change index across the selected metrics.
- CSV export includes only derived metrics and reflects the current filters.

## Notes & Limitations

> **Note**
> Advice summaries are descriptive and do not recommend actions.

> **Caution**
> Advice summaries require at least 3 runs in each scope. If either scope is thin or empty, the panel shows “Insufficient data.”

> **Note**
> CSV exports reflect the current filters and do not update after download.

## Advanced Usage

1. Select a goal intent that matches what you want to emphasize.
2. Adjust the goal weights to match your priorities.
3. Re-run Advice after updating weights to compare the weighted summary.
