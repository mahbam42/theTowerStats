# Calculator Tools

This page is **User Guide**. It explains how to use the Calculator Tools dashboard.

## Overview

Calculator Tools provides quick, descriptive calculators for game speed timing and lab research speedups based on your inputs.

## When to Use This

- You want to estimate your effective game speed from a recent run.
- You want to compare expected timing across different game speed settings.
- You want to understand the cell costs tied to lab speedup boosts for mission goals.

## How to Use

### Game Speed Calculator

1. Select **Calculator Tools** from the navigation.
2. Select a run from the **Run** list.
3. Select a **Game speed** value.
4. Select **Wave Accelerator active** when the card was active.
5. Select **Calculate** to view results.

### Labs Speed Up Calculator

1. Select the number of **Labs unlocked**.
2. Select your current research progress in days, hours, minutes, and seconds.
3. Select a **Goal** tier.
4. Select **Calculate** to view the speedup requirements.

## How to Read the Results

### Game Speed Calculator

- **Derived game speed** is calculated from your run’s real time and waves completed.
- **Observed waves per hour** reflects the run you selected.
- **Expected waves per hour** shows the waves per hour implied by the selected game speed.
- **Estimated real time** shows how long the selected run would take at the selected game speed.

### Labs Speed Up Calculator

- **Remaining research time** shows the gap between your current progress and the selected goal.
- The results table lists each boost option with the minimum number of boosts needed and the total cells required.
- **Research time covered** shows the total research time produced by the listed boosts across your unlocked labs.

## Notes & Limitations

> **Note**
> Derived game speed is an estimate based on real-world time and can differ from the in-game speed label.

> **Note**
> The Run list includes your five most recent Battle Reports.

> **Note**
> Wave Accelerator calculations use your Wave Accelerator card level and the card Effect value.

> **Note**
> Labs Speed Up results assume all unlocked labs are running and that speedups apply to all active labs.

> **Note**
> Results are descriptive only and do not recommend specific actions.
