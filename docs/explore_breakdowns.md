# Explore Breakdowns

This page is **User Guide**. It explains the breakdown options you can use in Explore.

## Overview

Explore breakdowns let you group results by a specific category so you can compare totals across runs, tiers, presets, or sources.

## When to Use This

- You want to compare outcomes by tier, preset, or tournament rank.
- You want to see which sources contribute the most to a total.
- You want to split a total into enemy types or damage sources.
- You want to confirm which breakdowns work well with a chosen metric.

## How to Use

1. Open **Explore**.
2. Add a Breakdown line to your query.
3. Select one of the breakdowns listed below.
4. Run the query and review the grouped results.

## How to Read the Results

- Each breakdown becomes a group in the output table.
- Bar and donut charts repeat the same grouped totals shown in the table.
- A breakdown that shows no values usually means the selected metric has no data for the current scope.

### Breakdown List

- **Damage Source**: Groups damage totals by the named sources reported in Battle Reports.
- **Enemy Type**: Groups enemy destruction counts by enemy category.
- **Coin Source**: Groups coins earned by the reported coin sources.
- **Guardian Outcome**: Groups Guardian-related results by outcome type (for example, medals, shards, or modules).
- **Run**: Groups totals by individual run.
- **Tier**: Groups totals by tier.
- **Preset**: Groups totals by preset label.
- **Tournament Rank**: Groups totals by tournament rank when recorded.
- **Real Time Hour**: Groups totals by run-length hour buckets using the Battle Report Real Time duration.
- **Game Time Hour**: Groups totals by run-length hour buckets using the Battle Report Game Time duration.

## Notes & Limitations

> Note
> Some breakdowns depend on specific metrics. If a breakdown appears empty, try a different metric or widen your filters.

> Note
> Breakdown availability depends on what you have imported. Runs without the underlying values will not contribute to the grouped totals.

> Note
> Real Time Hour buckets are based on the run’s Real Time duration, where Hour 1 is 0–59 minutes, Hour 2 is 60–119 minutes, and so on.

> Note
> Game Time Hour buckets only appear when the Battle Report includes a Game Time line; missing values are grouped as Unknown.
