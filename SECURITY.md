# Security Policy

The Tower Stats takes security and player data protection seriously.

## Reporting a Vulnerability

Please report security issues in one of the following ways:

- GitHub Security Advisories (preferred for private disclosure)
- Email: mahbam42+tts@gmail.com

If you believe an issue is security-sensitive, do not open a public GitHub issue.
For non-security bugs or feature requests, use the standard GitHub Issues workflow.

## Response Expectations

We will acknowledge reports as soon as possible, and we will provide updates on scope and remediation status when available.
